# IN-BETWEEN — personal portfolio starter

A responsive React + Vite portfolio concept for Opemipo Ashiru, themed around people, technology, and HCI.

## Run locally

1. Install Node.js (LTS) if you do not already have it: https://nodejs.org/
2. Extract this folder and open it in VS Code.
3. Open Terminal → New Terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL Vite prints (usually http://localhost:5173).

## Before publishing

- Replace `YOUR_EMAIL@example.com` in `src/main.jsx` with your actual professional email.
- Replace the generic LinkedIn and GitHub URLs with your own profile URLs.
- Add a link to your CV, or change the `CV LINK TO BE ADDED` label to a real link.
- Replace abstract project illustrations with real screenshots, diagrams, photos, or permitted artefacts from your work.
- Expand each project into its own detailed case-study page when you have the content ready.
- Keep MTN work within confidentiality rules; only show artefacts you have permission to share.
- The website uses Google Fonts from the internet; use locally hosted fonts if you want it to work fully offline.

The project visuals are intentionally CSS illustrations, not fabricated screenshots of your actual work. The content is a starting point and should be edited to reflect your exact contributions and current interests.
